# Likhitha K Halappa - Personal Portfolio

Personal portfolio website for **Likhitha K Halappa** — Computer Engineering Undergraduate, Web Developer, and UI/UX Designer.

## 🌐 Live Preview
- **Live Website:** [https://likhitha7322.github.io](https://likhitha7322.github.io)

## 🚀 Features
- **Self-Contained Single File:** Zero external CDN requests or dependencies. All CSS, JavaScript, and SVG brand assets are bundled directly inline.
- **Client-Side Hash Routing:** Instant switching across 4 views (`#home`, `#about`, `#works`, `#contact`) with smooth fade-in animations and scroll-to-top.
- **Light & Dark Mode:** Native system color scheme adaptation (`prefers-color-scheme: dark`).
- **Fully Responsive:** Mobile-first layout optimized for small screens (375px) up to large desktop viewports (1280px+).

## 🛠️ Tech Stack
- **Frontend:** Semantic HTML5, Modern CSS (Grid, Flexbox, Custom Properties), Vanilla JavaScript
- **Icons:** Simple Icons (inlined SVGs in official brand hex colors)
- **Deployment:** GitHub Pages
